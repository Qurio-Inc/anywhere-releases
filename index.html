HOW IT WORKS

「閉じたら止まる」を、 なくす。

Macは普段、フタを閉じた瞬間に眠り、走っていたジョブも一緒に止まります。 anywhereは、あなたが決めた時間だけMacを眠らせない。 だから、閉じてカバンに入れても仕事は続きます。

ONにする

その瞬間から、放っておいても、フタを閉じても、Macは眠らなくなる。

閉じて、カバンへ

iPhoneのテザリングにつないでおけば、歩いている間もジョブは走り続ける。接続と電源の状態はパネルでひと目。

時間が来たら、自動OFF

選んだ時間で設定は自動で元通り。消し忘れの心配はありません。

FAQ

よくある質問

Macのフタを閉じてもスリープさせない方法はありますか？
通常のmacOSでフタを閉じたまま処理を続けるには、外部ディスプレイと電源接続が必要な 「クラムシェルモード」を使うしかありません。anywhereならメニューバーからONにするだけで、 外部ディスプレイなし・バッテリー駆動のままフタを閉じてもスリープしない状態にできます。
バッテリーだけで動きますか？
動きます。電源アダプタも外部ディスプレイも不要で、カバンに入れたまま処理を続けられます。 バッテリー残量はパネルで確認でき、残量が少なくなると警告を表示します。
OFFにし忘れても大丈夫ですか？
30分・1時間・2時間など時間を決めてONにすれば、時間が来た時点で自動的にOFFになり、 スリープ設定も元の状態に完全に戻ります。消し忘れでバッテリーを使い切る心配はありません。
料金はかかりますか？
無料です。MITライセンスのオープンソースソフトウェアとして、ソースコード全体を GitHub で公開しています。
安全なソフトですか？
初回セットアップ時に一度だけ管理者の許可を求めます。macOSではスリープ設定切替（pmset）専用の sudoersルール、Windowsでは電源設定用のScheduled Taskを登録するためで、それ以外の権限は使いません。 ソースコードが公開されているため、動作は誰でも検証できます。
Windowsでも使えますか？
Windows 10/11に対応しています。タスクトレイ常駐アプリとして動作し、フタを閉じたときの スリープ設定を自動で切り替え、OFFにすると元の設定へ復元します。
